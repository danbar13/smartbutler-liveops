# LiveOps Digest Analyzer & Reporter

## Purpose
This skill equips the agent to build, test, and maintain the LiveOps Digest application. The tool ingests operational logs, shift reports, guest issues, and maintenance tickets, detects recurring failure patterns, and outputs an actionable morning executive briefing.

## Target Architecture
- **Language/Framework**: Python 3.11+ (FastAPI backend + lightweight CLI/Streamlit frontend) OR Node.js/TypeScript (Fastify/Express + React/Tailwind).
- **Storage/Input**: Local ingestion folder (`./data/logs/`) supporting `.json`, `.csv`, and raw unstructured `.txt`/log entries.
- **Output**: 
  - Executive Markdown Briefing (`./data/reports/daily_briefing_YYYY-MM-DD.md`)
  - Clean HTML/Web View for morning standup meetings.

## Analysis Logic & Heuristics
When processing raw logs, the system must extract:
1. **Recurring Room/Unit Incidents**: Flag any specific room, floor, or asset that appears more than once within a 48-hour window.
2. **Systemic Equipment Trends**: Categorize issues (HVAC, Plumbing, Locks/Keycards, Wi-Fi, Water Pressure, Elevators).
3. **Response & Resolution Bottlenecks**: Measure duration between incident logged and incident closed. Highlight unresolved tickets older than 2 hours.
4. **Guest Impact Score (1-5)**: Weight severity based on sentiment keywords (e.g., "demanded compensation", "could not sleep", "leak", "safety").
5. **Action Items for Morning Standup**: 3-5 concrete preventive assignments for maintenance and front-desk teams.

## Operational Standards
- Code must be modular: Separate `parser`, `analyzer`, `report_generator`, and `ui/server`.
- Provide mock dataset generators (`generate_mock_logs.py` or `.ts`) covering 3 days of realistic hotel/facility operations with deliberate recurring anomalies.
- Fully runnable out of the box with zero external SaaS dependencies (use local heuristics or direct Gemini API if LLM summarization is required).
